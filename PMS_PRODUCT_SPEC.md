**Edge Cases בpanel זה:**
- אורח עם חדר לא שובץ → שורה מוצגת באדום + "!חדר לא שובץ עדיין"

- אורח שמסומן בBlacklist → 🚫 badge + הודעת אזהרה + נדרש אישור מנהל
- קבוצה → badge "GROUP: כנס ABC" + כפתור "צ'ק-אין קבוצתי"

```
תצוגה נוכחית: [BAR ▼]
             ┌─ BAR (Best Available)
```

## 8.2 Pricing Rules Engine — Business Logic

```
כל הזמנה שנכנסת עוברת את הרצף הבא:

1. בסיס: מחיר BAR לתאריך×חדר
2. כלל: תאריך החסום? → SÃO REACHABLE
3. כלל: MinLOS? → הזמנה < MinLOS → חסום
4. כלל: CTA? → הגעה ביום זה → חסום
5. כלל: CTD? → יציאה ביום זה → חסום
6. כלל: Early Bird → Booked 30+ days ahead → -10%
7. כלל: Last Minute → <48h + occ<60% → -15%
8. כלל: LOS Discount → 5+ nights → -8%
9. כלל: Weekend Premium → Fri/Sat → +35%
10. כלל: High Occ → Occ>85% → +20%
11. תוצאה: מחיר סופי

חוקים = ordered by priority, אפשר להגדיר cumulative/exclusive
```
