# UI references (real hotel PMS screens)

Source: public vendor help centers, collected 2026-10-13.

- `cloudbeds-dash-3.png` — **primary reference for /pms "היום"**: Cloudbeds new Dashboard (2025).
  Date card + occupancy donut (available / booked / out of service / blocked) on the side;
  "Activity" card with tile tabs (Arrivals, Departures, In-house, Stayovers, Bookings, Cancellations, Overbookings);
  table Guest | Accommodation | Stay (dates + nights/adults/children chips) | Status (Check-in button) | row actions;
  footer toggle "View all arrivals" + arriving guests count.
  https://myfrontdesk.cloudbeds.com/hc/en-us/articles/16873372577435-Get-to-know-your-new-Dashboard
- `cloudbeds-dash-4.png`, `-5.png` — Forecast: KPI boxes (Occupancy, Room nights, ADR, RevPAR, Revenue) + chart / availability grid per room type.
- `cloudbeds-dash-1.png`, `-2.png` — previous Cloudbeds dashboard (Reservations tabs, Today's activity, 14-day outlook).
- `mews-dashboard.png` — Mews Operations dashboard (Best PMS, HotelTechAwards 2025): sections Tasks, Reservations, Spaces (dirty/out-of-service donut), Customers, 7-day Occupancy table (arrivals/departures/stayovers per day), Finance, Reports.
  https://help.mews.com/s/article/your-dashboard
