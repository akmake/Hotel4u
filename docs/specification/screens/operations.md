# חדרנות תחזוקה ובטיחות
8 מסכים. לכל מסך נוסף החוזה הרוחבי ב־02; זו הצעת מוצר, לא רשימת כפתורים שהועתקה ממערכת קיימת.
דרישת חובה מתייחסת לאישור הרשומה או הפעולה העסקית; בשדות חיפוש וסינון אין בכך דרישה למלא פילטר. חובה מותנית מפורטת בשורה. ברירת מוצר מוצעת אינה חובה חוקית. שמירת טיוטה מאפשרת חסרים ומסמנת אותם לפני אישור. פרטי מערכות חיצוניות אינם מוקלדים במקום תשובת ספק.
