# מאגר ידע: מה מלון צריך

המאגר כתוב במילים שלנו. כל קובץ מתאר מודול: מה המלון צריך ולמה, אילו מצבים יש, מה הכללים, מה הבדיקות ומה מקרי הקצה.

- **המקור:** ידע מקצועי שנאסף מתיעוד של מערכות ניהול מלון (OPERA, ‏Optima) ומהניסיון של sterni. **אין כאן טקסט מועתק, אין צילומי מסך ואין תיאור של מסכים של אחרים.** העיצוב והמסכים שלנו נבנים מהידע הזה.
- **שימוש:** לפני שבונים יכולת, קוראים את הקובץ של המודול. אחרי שבונים, מעדכנים את הסטטוס ב־[gap-map.md](../gap-map.md).
