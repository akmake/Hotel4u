# משימה: סבב השלמה למפת הפערים (למודל הבא)

## הקשר: מה כבר קיים
- `docs/product/knowledge/01–14*.md`: ידע במילים שלנו לכל מודול, שנאסף מ־OPERA, מ־Optima ומ־sterni. זה המקור לעבודה.
- `docs/product/gap-map-src/gap-map.src.md`: **מקור** מפת הפערים. כאן עורכים.
- `docs/product/gap-map-src/gen_gapmap.py`: מייצר את `docs/product/gap-map.md`, כולל טבלת הסיכום. **לא עורכים את `gap-map.md` ידנית.**
  - הרצה מהשורש: `python docs/product/gap-map-src/gen_gapmap.py docs/product/gap-map-src/gap-map.src.md docs`
- **פורמט שורה:** `| יכולת | סטטוס | אצלנו | מקור | הערה |`
  - **סטטוס:** אחד מ־✅ (קיים) / 🟡 (חלקי) / ❌ (חסר) / 🔍 (לבדוק).
  - **מקור:** טוקנים מופרדים ברווח. `O104` = עמוד 104 ב־OPERA. `P57` = עמוד 57 ב־Optima. כל טקסט אחר (למשל `sterni/Group`) מוצג כקוד.
  - **כל סעיף** מתחיל ב־`## N. שם` ובשורה `ידע: [knowledge/…](knowledge/…)`.

## מה לעשות

### שלב 1: סנכרון ידע ← מפה
עוברים על כל קובץ ב־`knowledge/`. לכל יכולת, כלל או מצב שמתואר בו ואין לו שורה בסעיף המתאים במפה, **מוסיפים שורה**.
- **דוגמאות ידועות שחסרות:**
  - רישום פניות שנדחו (turnaway) וסיבה.
  - **גלגול No Show ליום הבא.**
  - תעריפים: שימוש יומי / חינם / שימוש בית / BAR / מכפיל ותוספת / מינימום ומקסימום אנשים / הזמנה מוקדמת.
  - **חיפוש תעריף לפי טווח מחיר.**
  - **זמינות פריטים** (עריסה, מיטה מתקפלת).
  - **הקצבה בחבילה:** שעות תוקף, קודים חלופיים, רווח והפסד, לוח רישום (כל X לילות, הקצבה צפה, לוח 14 יום).
  - **עמלה מושהית** (בירור / עד תשלום החייב / כבר קוזזה). מחזור החיים של שיק עמלה.
  - **הגבלות:** "מינימום עד", הנחה לאתר, היסטוריית הגבלות.
  - **בלוק:** "כתפיים", גמיש / לא גמיש / עד מגבלה, שחרור מתגלגל, תאריך החלטה, הסתרת מחיר.
  - **חשבונות:** סגנונות הדפסה. **שעת תוקף לחיוב אחרי עזיבה.** הפקדה באמצע משמרת. מצב קופאים. עודף או חוסר שעובר למחר.
  - **חייבים:** סל ביניים לפני העברה, כרטיסי אשראי כחייב, מבט שנתי, איחוד חובות וביטול איחוד.
  - **משק:** מצב חדר (Condition), נקודות לחדרנית, תחזית למשק, ערב לפי מצב.
  - **קבלה:** השכמה לכל אורח ב־Share, מצב השכמה (בוצע / לא ענה).
- **לשורה חדשה:** מקור = טוקן O או P אם ידוע, אחרת `ידע`. וסטטוס אחרי בדיקה בקוד.

### שלב 3: סימון "ידע חלקי"
- **בראש כל סעיף שהידע בו חלקי**, שורה אחת: `> ידע חלקי: …` עם מה חסר ולמה.
