# מעקב מימוש מנוע חשבונאי ישראלי

מקור: [מפרט 14](../specification/14-israel-accounting-engine-implementation.md). התחלה: 17.10.2026. עדכון: 18.10.2026.

## תכולה שנבנתה

- מסך `/pms/fin/accounting` מחובר לשרת: ישות משפטית, חשבונות, פקודות והיפוכים, תקופות, מאזן בוחן, סדרות בהכנה, תיעוד החלטות ציות ועיבוד ארכיון. נוסף לתפריט.
- LegalEntity, IssuerProfile גרסאי ושיוך נכס. אין מיזוג נכסים אוטומטי; סדרות מנפיק נשמרות בהכנה ומספור היסטורי לא שוכתב.
- חישוב כסף עשרוני מדויק ב־BigInt, עיגול שורה וחלוקת שארית. הספר החדש שומר מחרוזות עשרוניות; Invoice הוותיק עדיין כולל התאמה ל־Number בגבול הישן.
- הנפקת Folio, ידנית וזיכוי כותבות מסמך, מונה, audit ואירוע outbox באותה טרנזקציה. אין fallback ללא טרנזקציה. רשת לרשות המסים לאחר commit ושחרור הנעילה.
- שלושת מסלולי ההנפקה שומרים idempotency key ו־payload hash. המסלול הידני והזיכוי מחייבים כעת `idempotencyKey` באורך 8–80, אותיות לטיניות/ספרות/מקף/קו תחתון. דיאלוג זיכוי שומר מפתח עד סגירתו.
- זיכוי לפי שורת מקור ויתרת נטו/מס/ברוטו, כולל אגורות ותחרות בין בקשות. זיכויים היסטוריים ללא קישורי שורות וסיכומי מקור לא עקביים נחסמים לבדיקה.
- הגנות save/query/replace/bulk/delete למסמכים סופיים. רשומות ספרים/אירועים/מס/פרופיל/ארכיון בלתי משתנות דרך Mongoose; הגדרת הרשאות DB ישירות עדיין נדרשת.
- ספר כפול ידני ב־shadow: חשבונות, פקודה מאוזנת, מקור ייחודי, היפוך מקושר, נעילת תקופה ומאזן בוחן. אין מיפוי הכנסה אוטומטי ללא מדיניות מאושרת.
- 15 שערי שחרור עם מקור, גרסה, בעל סמכות, אסמכתה ותוקף; TaxRule גרסאי והכרעה שחוסמת כלל חסר/חופף/לא מאושר/ללא ראיות. מסלולי המס הישנים טרם הוסבו במלואם.
- חוזה ספק capture/query/refund/queryRefund, intent לפני חיוב, unknown recovery בבירור בלבד, reservation ליתרת החזר גם ב־pending/unknown, ו־Inbox פנימי לאירוע מאומת. אין ספק חי או webhook ציבורי ללא אימות ספק.
- Outbox עם lease token, retry וכשלים; worker לארכיון JSON קנוני ו־SHA-256, הורדה בתחימת נכס ואימות hash. הארכיון unsigned ואינו PDF חתום.
- inventory למיגרציה לקריאה בלבד: איתור חריגים וקבוצות מועמדות לבדיקה. אין apply אוטומטי או שכתוב היסטוריה.

## הפעלה ומעבר

לאחר הפעלה מחדש של שרת ולקוח הפיתוח הרגילים, המסך נמצא בתפריט **הנהלת חשבונות**. תחילה מגדירים ישות ומכינים חשבונות ותקופה. הישות מתחילה ב־shadow; אין מתג שמכריז על מוכנות לפעילות אמת.

שינויי ההנפקה דורשים Replica Set או mongos התומך בטרנזקציות. אין לפרוס ל־standalone. יש לוודא יצירת indexes ייחודיים. חזרה לגרסת קוד קודמת מחייבת השבתת הנפקה בזמן הבירור; אין למחוק ספרים או מסמכים כדי לבצע rollback.

ה־API תחת `/api/pms/accounting` מאמת תפקיד ונכס. הנהלה וכספים כותבים; מבקר ובעלים צופים. החלטת ציות נרשמת בידי כספים או מנהל רשת/מערכת. הרשאות רשת קיימות לא הורחבו.

## QA מבודדת

הסוויטות החדשות אינן משתמשות ב־MONGO_URI של המלון או ב־.env שלו. הן מקימות MongoDB זמני. משתמשים בקובץ mongod דרך MONGOMS_SYSTEM_BINARY או עותק Windows מקומי ב־node_modules/.cache/accounting-mongo. אם אין עותק, mongodb-memory-server מוריד MongoDB 7.0.14 הרשמי בהרצה הראשונה; ההתקנה הרגילה אינה מורידה אותו אוטומטית.

תצוגת QA: `npm --prefix server run qa:accounting:preview`, לקוח עם `API_PROXY=http://127.0.0.1:4897`, וכניסה ל־`/qa/accounting-preview.html`. שרת התצוגה מאזין ב־loopback בלבד ומשתמש במשתמש ונתונים זמניים; אינו מתאים לחשיפה או לייצור.

Inventory: מגדירים MONGO_MIGRATION_URI מפורש ומריצים `qa:accounting:inventory -- --output=<new-file>`. הקובץ אינו נדרס והכלי אינו משנה נתונים.

כל שערי השחרור נשארים פתוחים עד השלמת הראיות. העבודה הנוכחית אינה השלמת כל מפרט 14.
